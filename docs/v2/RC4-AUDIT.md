# RC4 Linux 有限预览整改记录

审计基线为 RC3 提交 `1b219f3fa530e1c78e96e8169c7c1790441a3882`。候选版本为 `2.0.0rc4`。本次推送范围是 Linux 受保护运行有限预览，跨平台通用、无交互且可签发完整发布 PASS 的 v2.0 正式版继续 **NO-GO**。

## A–F 与审计编号

| 阶段 | 编号 | 状态与证据范围 |
|---|---|---|
| A | 003 | 开放。缺少验证过的 Windows 客体运行器。 |
| A | 004 | 默认 CLI 和 MCP 关闭宿主执行，旧开关返回参数错误。显式 `unsafe-local-run` 保留本地调试，报告强制不可发布。 |
| A | 005 | 私有收据目录和原子文件写入。POSIX 创建时限定 0700/0600；Windows 范围限定为运行账户的 DACL。跨用户独立测试覆盖见回归记录。 |
| A | 006 | 受保护模式扫描原始输入，项目 `.verifyignore` 及备份名称不能绕开覆盖。尚无管理员授权排除策略。 |
| A | 013 | Windows 在读取前核对已打开句柄的最终路径及文件身份。高并发替换测试仍待完成。 |
| A | 014 | 自定义规则新增匹配超时、总预算和输入配额。超预算返回 UNKNOWN。 |
| A | 022 | 受保护出口筛选字段；包作业停止上传宿主详细证据。显式调试仍有私有明细。 |
| B | 001、009 | 开放。Linux 客体退出 0 不代表真实覆盖，无法签发受保护 PASS。 |
| B | 011 | 部分。使用私有 HMAC 密钥和证据目录，需要独立签署身份。 |
| B | 012 | 开放。正常取消和超时已实测，宿主或 Docker 异常停机后的回收仍待验证。 |
| B | 015 | 管理员可设单命令超时，带有硬上限。OOM、超限和更多资源配置仍需专门分类。 |
| B | 020 | 共享内核和本地 Docker 属于可信计算基。独立内核运行器与审计保持开放。 |
| B | 021 | CI 按可复验的镜像摘要拉取。镜像签名、SBOM、离线依赖链待补。 |
| C | 002、016、018、027 | 开放。全语言、多仓库、Git 精确修订与合并、大型项目的输入策略留待验收。 |
| D | 010 | 部分。受保护语法诊断返回行号、报告内别名与固定修复建议。完整本机路径定位及其余检查待做。 |
| D | 017 | 部分。CI 分开验证 Linux 隔离和构建产物；正式发布仍缺独立受保护完整 PASS。 |
| D | 023 | 受保护报告提供 `PROTECTED_INPUT_EXCLUDED` 和计数，隐去真实文件名。 |
| D | 024 | 配置、Docker/镜像可用性和运行证明分开报告。配置通过不代表能够执行全部测试。 |
| D | 028 | MCP 不公开原始项目或策略摘要。项目清单仍使用本机快照与策略摘要。 |
| E | 008、019 | 部分。MCP 不要求额外项目授信参数，仍需管理员预部署 Linux 隔离。真实桌面 Agent 自然语言闭环未完成。 |
| E | 025 | 部分。报告提供排队、快照、验证、封存阶段，进程崩溃恢复待完成。 |
| E | 026 | 对父目录中多个项目要求相对项目路径。更复杂的嵌套工作区待验证。 |
| F | 007 | 开放。L01–L18 尚未全通过，独立审计及 Windows 客体测试待完成。 [RC3 验收矩阵](RC3-SECURITY.md) |

## 复验

- `uv run python -m unittest discover -s tests -v` 覆盖证据权限、项目忽略规则、参数拒绝和 MCP 协议。
- `uv run python conformance.py` 验证三态和命令退出码。
- CI 使用真实 Linux Docker 复验默认断网、宿主隔离、取消和超时，独立校验 wheel 和源码包。开发包 provenance 明确记录 `protected_release_approved: false`。
