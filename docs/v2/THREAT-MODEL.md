# 验证 Worker 威胁模型

项目源码、依赖和报告内容都可能由项目维护者控制。RC3 开发版为 MCP 关闭宿主动态执行。Linux 候选使用默认断网容器，输出由宿主固定字段重建。未获得完整证明时返回 `security_status=UNAVAILABLE` 并阻断发布。显式可信 CLI 的临时副本仍使用操作者系统身份。 [RC3 防外泄状态](RC3-SECURITY.md)

| 边界 | 资产和失效方式 | 验收条件 |
|---|---|---|
| MCP 请求与本地根目录 | 未授权报告读取、浏览器跨站请求、路径绕出授权根 | 授权负测，允许来源及根目录验证，任务归属复核 |
| 被测代码与原树 | 测试、变异或构建改写源码，残留子进程 | 原树哈希恒等，取消/超时后子进程树退出 |
| 代码修改与裁决进程 | 被测代码写入收据或虚构运行次数 | 发布证据在不同权限边界生成，绑定源码和策略 |
| 持久化证据 | 旧或被修改的收据被重取为 PASS，密钥进入日志和浏览器截图 | 校验文件、清单与判定，所有渠道测试脱敏 |
| MCP 响应 | 自由文本、路径、截图和错误信息绕过输出策略 | 固定字段重建，拒绝未认证证据，双传输验证 |
| 启动与供应链 | 恶意依赖钩子、宿主 Docker 或 SSH IPC、未经审查的镜像 | 管理员固定离线镜像，验证 Linux/Windows 进程、文件与 IPC 边界 |
| 外部依赖和网络 | 验证进程泄露凭据或被任意外部内容影响 | 默认受控出网，隔离缺失记 UNKNOWN |
