# 验证 Worker 威胁模型

区分授权的自有测试项目和不可信源码。后者可能包含有副作用的构建、依赖解析、测试或浏览器内容。当前候选对未授权工程关闭动态执行，可信工程使用工作副本、分离进程和收敛的环境变量。副本隔离不提供操作系统身份、文件系统或网络隔离证明。

| 边界 | 资产和失效方式 | 验收条件 |
|---|---|---|
| MCP 请求与本地根目录 | 未授权报告读取、浏览器跨站请求、路径绕出授权根 | 授权负测，允许来源及根目录验证，任务归属复核 |
| 被测代码与原树 | 测试、变异或构建改写源码，残留子进程 | 原树哈希恒等，取消/超时后子进程树退出 |
| 代码修改与裁决进程 | 被测代码写入收据或虚构运行次数 | 发布证据在不同权限边界生成，绑定源码和策略 |
| 持久化证据 | 旧或被修改的收据被重取为 PASS，密钥进入日志和浏览器截图 | 校验文件、清单与判定，所有渠道测试脱敏 |
| 外部依赖和网络 | 验证进程泄露凭据或被任意外部内容影响 | 默认受控出网，隔离缺失记 UNKNOWN |
