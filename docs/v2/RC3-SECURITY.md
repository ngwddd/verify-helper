## 运行范围

隔离候选由操作者在有独立管理边界的 Linux 主机启用。使用已审查、预加载的固定镜像 ID，镜像须包含 GNU tar、timeout、sh 和 `/usr/local/bin/python`。服务只接入本机 Docker 套接字，不从项目读取镜像或容器参数，不自动下载镜像。镜像、Docker 守护进程和宿主验证器属于可信计算基。

当前只在容器内调度标准库 unittest。容器退出码只记录为有限的状态码。可证实的用例覆盖未从可信来源取得，因此即使进程退出为 0，测试与隔离裁决仍记为 UNKNOWN。C/C++、JS/TS、浏览器和项目自定义运行契约在受保护模式下缺少已验证适配器，适用时均保留 UNKNOWN。旧版显式可信 CLI 仍按原有流程处理由操作者审查过的自有代码。

## 回归入口

`uv run python -m unittest discover -s tests -p test_rc3_boundary.py -v` 可验证报告和宿主回退保护。GitHub Actions 的 Linux isolation acceptance 作业使用实际 Docker 运行 `sandbox_acceptance.py`。两组测试使用合成数据。 [Linux 实测日志](https://github.com/ngwddd/verify-helper/actions/runs/44830717667/job/136614678822)
