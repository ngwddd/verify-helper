# RC1 release checklist

- Verify the exact candidate SHA on Windows and Linux and record wheel and sdist digests.
- Review every P0 regression against baseline or record remaining evidence gaps.
- Verify source tree invariance, process cleanup, manifest tamper handling and privacy output.
- Verify the scoped MCP tool list, legacy and current protocol, reconnect, cancellation and HTTP negative paths.
- Check authorization and verified OS isolation before any cross-repository execution.
- Record the target client matrix, declared adapters and remaining scope limitations.
- Identify an independent operating-system worker and evidence writer for untrusted execution.
- Record an Owner decision before publishing any release.
